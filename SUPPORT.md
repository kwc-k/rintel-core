# Support

Start with [README.md](README.md) and `./rintel doctor`. For a reproducible installation or product problem, use [GitHub Issues](https://github.com/kwc-k/rintel-core/issues) and include the release tag, OS/architecture, command, expected result, actual result, and redacted diagnostic output. Do not paste private repository contents, tokens, or databases into an issue.

Rintel Core is community-maintained; support is best-effort, not a service-level commitment. For security reports, follow [SECURITY.md](SECURITY.md).
